# Private

Teacher-only material that must **never** be published on the public website.

**Belongs here:** tests, quizzes, answer keys, solutions, marking schemes, teacher-only notes.
**Does not belong here:** anything meant for the public site (use `site/`).

## Contents

- [module-01-about-this-computer/lesson-01-answers.md](module-01-about-this-computer/lesson-01-answers.md) — answers for Module 1, Lesson 1.
- [module-01-about-this-computer/lesson-02-answers.md](module-01-about-this-computer/lesson-02-answers.md) — answers for Module 1, Lesson 2.

Organize by module, matching the folder names in `site/modules/`.

## Rules

- This folder is outside the Quarto project (`site/`), so it is never rendered into `docs/`.
- Never link to files here from the site.
- Teachers receive these materials as Google Docs shared with them directly.
- Tag each file with the curriculum expectation codes it assesses.
- Every quiz and test includes a code-reading and tracing section (see [../project-docs/teaching-approach.md](../project-docs/teaching-approach.md)).
