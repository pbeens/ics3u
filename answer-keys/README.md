# Answer Keys

Answer keys and teacher-only material. This folder is in the public GitHub repository, but it is **never** published on the website or linked from it.

**Belongs here:** answer keys, solutions, marking notes, teacher-only notes.
**Not yet decided:** quizzes and tests that must stay secret (anything here is public).
**Does not belong here:** anything meant for the public site (use `site/`).

Organize by module, matching the folder names in `site/modules/`.

## Rules

- This folder is outside the Quarto project (`site/`), so it is never rendered into `docs/`.
- Never link to files here from the site.
- Lesson plans may name this folder in plain text so teachers can find it.
- Tag each file with the curriculum expectation codes it assesses.
- Every quiz and test includes a code-reading and tracing section (see [../project-docs/teaching-approach.md](../project-docs/teaching-approach.md)).
