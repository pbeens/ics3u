# lesson-tools

Shortcodes for lesson pages.

- `{{< lesson-code >}}` — table of this lesson's example programs: `.py` download, notebook on GitHub, and Open in Callysto | Colab. Built from the files in the module's `examples/` folder.
- `{{< feedback >}}` — short feedback paragraph with a link to the GitHub feedback form, prefilled with the page title and address.
