ICS3U: Introduction to Computer Science

Grade 11, University Preparation · Taught in Python

Ready-to-teach lessons for Ontario ICS3U, each with slides, runnable code, and teacher prompts. Teaching a similar course in Python somewhere else? These lessons work for you too.

How the course works

  • Read first. Students read, predict, and trace real code before they write their own.
  • A spiral, not a list of topics. Output, input, decisions, loops, and lists all appear early inside programs students read, then return in every module at a deeper level.
  • Real programs from day one. The first program asks the computer what processor it has, not “Hello, World”. Later modules check specs, run benchmarks, test password strength, troubleshoot the network, and track down what’s filling the hard drive.

More about the course design →

The whole course is free, with no ads and no sign-up. If it saves you time, a coffee now and then is always appreciated.

Modules 1–4 run on any computer with Python and files that stay saved. The whole course needs open computers students fully control; refurbished computers are ideal.
