Read and predict

Read this program without running it. Write your answers, then type your prediction in the box and press Step.

  1. How many lines will it print?
  2. Which lines will be exactly the same on every computer?
  3. Which parts will change from computer to computer?
  4. Which line of code prints Done?
import platform

print("Python report")
print("System:", platform.system())
print("Python version:", platform.python_version())
print("Done")

Modify

Make each change, predict the new output, then run it.

  1. Add a line that prints the CPU type with the label CPU:.
  2. Change the first line so it prints your name instead of Python report, for example Python report by Sam.
  3. Move print("Done") to the top of the program. What happens? Why?

Make

On your classroom computer (Thonny, IDLE, or VS Code), write a program that prints:

  • a title line, and
  • three labelled facts about the computer: its CPU type, its operating system, and the operating system’s version number (platform.release()).

Run it, then copy its output under your code as a comment.

import platform

system = platform.system()
version = platform.python_version()
print("Running on", system)
system = "my computer"
print("Python", version, "on", system)
  1. What does system hold after line 3? After line 6?
  2. Why does the last line print my computer and not the operating system’s name?

Spot the mistake

This program has a mistake. Predict what will happen, then press Step to find out.

  1. What type of error is it?
  2. Which line does it point to?
  3. Python makes a suggestion. What is it? Fix the program on your classroom computer and run it.
import platform

version = platform.python_versions()
print("Python version:", version)

Make

  1. Run print(dir(platform)) (after import platform) and choose one function you haven’t used yet. Check what it does in the platform documentation.
  2. On your classroom computer, write a program that stores its answer in a variable with a clear name and prints it with a label.
  3. Add a comment at the top explaining, in your own words, what the function tells you.
