Programs that ask

import platform

name = input("What's your name? ")
print(f"Hi, {name}! This computer runs {platform.system()}.")
print(f"Its processor is {platform.machine()}.")
  • input() prints the question, waits, then hands back what was typed
  • Input → processing → output

Open with the problem: “Every program so far talks at the user. Real tools ask questions: Are you sure? Enter your password. Which drive? Today our programs talk back.” Run it on the classroom computer. TEACHER PROMPT (input): “input prints the question, waits for the user to type and press Enter, then hands back what they typed. We store it in a variable like any other value. Note the space after the question mark. This is the pattern of almost every program: input, processing, output.”

A first look at decisions

import platform

system = platform.system()
if system == "Windows":
    print("Open File Explorer to see your files.")
elif system == "Darwin":
    print("Open Finder to see your files.")
else:
    print("Open your file browser to see your files.")
print("Your course folder is called ics3u.")

Predict on three computers first: Windows, Mac (Darwin), this web page. Which lines are skipped here? Does line 10 run everywhere? TEACHER PROMPT (if, first reading): “if asks a yes-or-no question. == means is equal to: two equals signs, because one already means store. If True, Python runs the indented lines and skips the rest of the if; if not, it checks the elif, then falls through to else. Exactly one branch runs. Module 2 is all about decisions; today, just read them.”

A first look at loops

import platform

facts = [platform.machine(), platform.system(), platform.node()]
for fact in facts:
    print("-", fact)
print("Done:", len(facts), "facts")

Ask: how many values in the list (square brackets)? How many times does line 5 run? What does fact hold each time (Variables panel)? TEACHER PROMPT (for, first reading): “for fact in facts means: take each value in the list, one at a time, call it fact, and run the indented lines. When the list runs out, carry on below. Loops are Module 3; lists are Module 5.”

Spot the problem

cores = input("How many cores? ")
print("Threads:", cores * 2)

Logic error: no crash, wrong answer. cores is the string “4”, and * repeats a string: 44. Fix: int(cores) * 2.
