Module 1 Assignment: Computer Report Card

Module 1 — About This Computer · For students

For students. Covers Lessons 1–2. Work on your classroom computer (Thonny, IDLE, or VS Code). Download the starter file: this one file is your whole assignment. Save it as report_card.py in ics3u/module-01/assignment/ in your course folder, answer Parts A and C in its comments, write your Part B program in it, and hand it in. When it works, copy it into ics3u/toolkit/: it’s the first program in your toolkit. · Module 1 overview

Ready to use for Lessons 1–2. More parts will be added as Module 1 grows.

Part A: Read

Read this program without running it, then answer the questions in Part A of your starter file (the comments near the top). Use the line numbers shown.

import platform

name = platform.node()
cpu = platform.machine()
print("Report card for", name)
print("CPU:", cpu)
cpu = "unknown"
print("Checked:", cpu)

  1. How many lines will it print?

  2. Fill in a trace table. Every line that runs gets a row; blank lines don’t. Line 1 is filled in for you.

    Line name cpu Output
    1 — — —
    3
    4
    5
    6
    7
    8

  3. What does the last line print? Explain why.

  4. How many times does the program ask the computer for its CPU type?

Part B: Write

In Part B of report_card.py, write a program that prints a computer report card for the computer it runs on.

Your program must:

  1. Print a title line that includes the computer’s name.
  2. Report at least five facts, using five different platform functions. At least one must be a function you found yourself with dir(platform) or the documentation.
  3. Store each answer in a variable with a clear name before printing it.
  4. Print each fact with a clear label.
  5. Start with a comment giving your name, the date, and what the program does.

Example of the style (your facts and labels will be different):

Report card for LAB-PC-14
CPU type: AMD64
Operating system: Windows
...

Part C: Run It in Two Places

  1. Run your program on the classroom computer and paste the output into Part C of your starter file.
  2. Paste the same program into the box below and run it in the browser. The first run downloads Python into the browser (about 10 MB), so it can take a few seconds.
  1. Answer in two or three sentences each, in Part C of your starter file:
    1. Which facts were the same in both places? Which were different?
    2. Why are they different? Where did the program actually run each time?
    3. Name one mistake you made while writing the program, and explain how the error message helped you fix it. If you made none, explain what an AttributeError would tell you.

Success Criteria

Level 1–2 Level 3 Level 4
Knowledge (Part A) Some predictions correct Trace table and output correct Correct, with clear explanations of why
Application (Part B) Runs, but fewer than five facts or no variables Five labelled facts stored in variables Also uses a self-found function well, with very clear names and labels
Thinking (Part C) Lists differences Explains where the code ran Explains clearly, using evidence from both outputs
Communication Few comments or unclear labels Header comment; clear labels Clear, consistent comments, names, and output
