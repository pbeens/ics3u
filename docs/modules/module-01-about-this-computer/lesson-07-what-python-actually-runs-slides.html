The CPU can’t read text

  • Your .py file: letters, brackets, quotation marks
  • The CPU: only numbers, its own machine code (arm64, x86_64)
  • So how does print() ever happen?

Open with the problem: “In Lesson 1, arm64 and x86_64 were names for the instructions a CPU understands. Your .py file is text. The CPU can’t read text. So how does print() ever happen?”

Two ways to translate

  • Compiler: translates the whole program ahead of time into an executable the CPU runs directly
  • Interpreter: reads the program and carries it out as it goes
  • Python: compiles your file to bytecode, then interprets the bytecode
report.py ─► interpreter ─► bytecode ─► one by one ─► CPU

TEACHER PROMPT (first use): “Source code is what we write, for people. Machine code is what the CPU runs: numbers, each a tiny instruction. Every CPU family has its own. A compiler translates the whole program ahead of time into an executable, like translating a whole book before it’s printed; Chrome and Word arrive that way. An interpreter carries the program out as it goes, like an interpreter at a meeting. Python does both: it compiles the whole file into bytecode, simpler instructions for Python itself, then interprets them one at a time. The interpreter, python3 or python.exe, is a compiled program: machine code.”

Looking at bytecode

Ask: which instructions came from line 2 (left-hand numbers)? Find the multiplication. Which instruction saves the answer in doubled? LOAD = fetch a value; STORE = save it under a name. “Still not machine code: Python’s own instruction set. The interpreter turns each into machine code as it runs. Versions differ slightly; the ideas don’t.”

Who built your Python?

import platform

print("Operating system:", platform.system())
print("Language:", platform.python_implementation(), platform.python_version())
print("Python was compiled by:", platform.python_compiler())

Run it here, then on the classroom computer. Windows: usually MSC (Microsoft’s compiler). macOS: Clang. Linux: GCC. The web page: Emscripten’s Clang, compiling to WebAssembly. If a compiler made the interpreter, what was it written in? CPython is written in C.

Application, language, or OS?

Windows · Python · Chrome · Thonny · macOS · Minecraft · JavaScript · Linux · Microsoft Word · Scratch · Android · VS Code · Java · iOS · python.exe

Pairs sort into three columns. Then the tricky ones: “Thonny and VS Code are applications for writing a language. Python is the language, a set of rules; python.exe is the application that runs it. The operating system runs underneath everything: it starts programs, gives them memory and files, and shares the CPU. When you ran os.getcwd(), Python asked the operating system.” Scratch is a language and an application (its editor).
