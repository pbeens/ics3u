Three kinds of error

Kind Python notices… You see…
Syntax before running no output; a message at a line
Run-time while running some output, then a traceback
Logic never it finishes, but the output is wrong

Students have met all three. Syntax: the apostrophe (L3), Lesson 7’s last-line error. Run-time: AttributeError (L2), TypeError (L5), FileNotFoundError (L6). Logic: the Windows path (L3), missing f (L4), 44 threads (L9).

The clinic: the routine

  1. Predict what it should do
  2. Run it
  3. Classify: syntax, run-time, or logic?
  4. Locate: which line?
  5. Explain the message (or expected vs. actual)
  6. Fix, and run again
