# Official Curriculum

*The Ontario Curriculum, Grades 10 to 12: Computer Studies (Revised 2008)*, Ontario Ministry of Education.

## Contents

- [ics3u-expectations.md](ics3u-expectations.md) — every ICS3U overall and specific expectation (14 overall, 57 specific), transcribed from the PDF and checked line by line against the rendered pages. **The only file to use for expectation codes and wording.**
- `computer10to12_2008.pdf` — the original Ministry PDF (72 pages). This is the authority; ICS3U is on printed pages 39–46.
- `computer10to12_2008.md` — full-document Markdown conversion of the PDF. Complete but not clean: some lines contain page-margin text or run together. Useful for searching the rest of the document (achievement chart, program planning).

## Rules

- Do not edit the PDF or the Markdown conversions; they are kept as received.
- Corrections go in `ics3u-expectations.md`, checked against the PDF.
- Ministry text is not republished on the site beyond short expectation quotations.
